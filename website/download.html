BEFORE YOU GET STARTED

再了解一点。

从安装到创作，我们帮你理清。
不确定设备架构，应该选哪个？＋

目前大多数 Android 手机与平板使用 ARM64，可先查看设备规格是否包含 arm64-v8a。x86_64 主要面向对应架构的 Android 模拟器。如果系统提示不兼容，请核对 Android 版本、处理器架构与图形支持。

下载没有开始，或无法访问 GitHub？＋

安装包托管在 GitHub Releases，本页通过 gh.b52m.cn 代理加速下载。 如果下载没有开始，请稍后重试或使用下方「直接下载链接」。 也可以进入完整发布页，通过 GitHub 获取对应文件。

使用前需要了解哪些限制？＋

项目仍在早期阶段。当前 APK 未启用 HEIC/HEIF，暂不支持原生图片剪贴板、屏幕吸色与手写笔压力/倾斜。大图表现取决于设备内存；重要文档请保留原件，并用 .pcraft 或 PSD 保留图层，PNG/JPEG 是合成图像。

可以下载 Windows、macOS 或在线版吗？＋

本移植仓库当前发布 Android APK，源码保留桌面、命令行与 WebAssembly 入口。如需其他平台，请前往上游项目了解构建方式与发布情况。本网站提供 Android 的实际发布文件。

如何更新，或反馈问题？＋

在同一项目的 Releases 下载新版本后，按系统提示更新。建议先备份重要作品。如果遇到问题，可前往 GitHub Issues 反馈设备型号、Android 版本与复现步骤；欢迎页也有 QQ 社群入口 1129505510。

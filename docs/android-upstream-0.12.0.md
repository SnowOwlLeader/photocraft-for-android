# Android 同步至 PhotoCraft v0.12.0

- 上游仓库：<https://github.com/storytold/photocraft>
- 官方版本：<https://github.com/storytold/photocraft/releases/tag/v0.12.0>
- 官方提交：`6a2d027ee2e7ca12afd248544ed2262b0fa078dd`。
- 合并基线：v0.8.2，`d43db3e153c76aefce9b32cef9099e458eaf17a8`。
- 安卓版本：`0.12.0-android.1`，versionCode `12001`。

通过干净 v0.8.2、现有安卓源码和官方 v0.12.0 三方合并，接入两个版本之间的完整源码更新，而非只修改版本号。沿用 Rust / egui / eframe / wgpu 原生架构、包名与本机原签名；这是独立修改版，不是官方安卓发行版。

## 上游更新

完整清单见官方发布说明和源码中的功能文档。此同步包含 PSD/PSB 读写、图层样式、智能滤镜映射、文字编辑与变形、绘画预览、内容识别移动、蒙版属性、导出采样、快捷键及工具设置持久化等改进。

v0.12.0 官方发布说明中的主要变化包括：

- 内容识别移动采用先粗略后精确的预览，改善大选区交互。
- 属性面板加入形状与蒙版的密度、羽化；文字变形载入图层现有参数并实时预览。
- 图案图章、背景橡皮擦与颜色替换工具补充实时笔触预览。
- PSD 智能滤镜映射从 14 种扩充至 41 种，并修正图层样式、颜色与格式兼容问题。
- 导出支持最近邻重采样，DDS 支持未压缩、BC1～BC3 和可选 mipmap。
- 工具选项和各工具画笔可跨重启保存，图层面板底部支持将所选图层编组。

以上是上游能力的同步范围；其中的超大文件测试规格不等于安卓文件管理器放宽 256 MiB 单文件限制，也不代表全部 Photoshop 滤镜或格式完全兼容。

上游仍处于 alpha 阶段，官方列出的未完成能力与安卓设备内存限制依然适用。桌面打印等平台专属功能不等于安卓获得系统打印服务。

## 保留与兼容处理

- 保留双指画布移动、缩放、旋转，以及取消首指笔触的局部缓存恢复。
- 保留图层触屏惯性滚动、左滑多选、长按菜单、排序和跨文档复制。将触控滚动状态接入上游按文档区分的 ScrollArea ID。
- 保留画笔下方独立像素铅笔入口；启用前保存原工具画笔，防止新版工具记忆把原画笔覆盖或把旧铅笔设置重新载入。
- 保留文字浮窗、字体导入、原生文件管理器、SAF、PSD 原路径保存和快速 PNG 导出。
- 安卓导出改用上游统一的 `ExportSettings::io_options`，让 DDS 压缩/mipmap、ICC/元数据、PSD 缩略图与最大兼容性等选项实际传入编码器；新增真实 DDS 文件头及解码回归测试。
- 保留窄屏菜单、工具组点按展开、图层浮窗、可见设置入口和默认第 5 档的 1～10 档 UI 设置。
- 保留 QQ 社群 `1129505510`，适配上游移至引擎的菜单命令表。
- 保留安卓键鼠输入补丁 `vendor/winit`。
- 保留本地 `website/` 及其测试和素材归属说明。

APK 使用原应用包名与签名，可覆盖升级。请安装与设备 ABI 对应的 APK；不需要先卸载。卸载会删除应用私有的 Works、暂存和恢复文件。

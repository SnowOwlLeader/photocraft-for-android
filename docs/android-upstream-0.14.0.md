# Android 同步至 PhotoCraft v0.14.0

- 上游：[storytold/photocraft](https://github.com/storytold/photocraft/releases/tag/v0.14.0)。
- 官方提交：`ff4738810134d7f7e68b49f2e4f231b686282ff3`。
- 三方合并基线：官方 v0.12.0，`6a2d027ee2e7ca12afd248544ed2262b0fa078dd`。
- 安卓版本：`0.14.0-android.1`，versionCode `14001`。

将现有安卓定制源码与官方 v0.12.0 → v0.14.0 的完整变化三方合并，包含中间 v0.13.0 的更新。沿用 Rust / egui / eframe / wgpu 原生架构，包名与原签名不变。这是独立安卓修改版，并非官方安卓发行版。

## 本次同步

接入上游图层重排预览、图层缩略图大小、图层效果折叠、工具组按住拖选、文字编辑和提交、动画缩放、导出与自动化检查等更新。v0.14.0 发布说明特别列出 View → Extras 隐藏移动工具变换框，以及 PSD slices、跨步采样溢出、PCX/XPM 内存预检、SVG 解压和内嵌图像尺寸、临时与恢复文件的加固。

以上描述同步范围；具体格式和功能边界继承上游 alpha 版本，并不代表完整 Photoshop 兼容。

## 安卓兼容

- 保留双指画布平移/缩放/旋转、首指笔触局部取消；双指导航立即应用目标视图，不叠加新版缩放过渡延迟。
- 保留图层触屏惯性滚动、左滑多选、长按菜单、排序及跨项目复制，同时接入上游图层尺寸和重排预览。
- 保留工具组点按展开；桌面按住拖选仅由鼠标使用，手机纵向滚动不误展开。
- 保留独立像素铅笔、文字浮窗和字体导入、键鼠补丁、原生文件管理器、SAF、PSD 原路径保存、快速 PNG。
- 保留窄屏布局、可见齿轮和 UI 1～10 档（默认 5），QQ 社群 `1129505510`。
- 保留本地网站、网站测试与素材归属说明；不修改网站旧版下载指向。
- 上游合并了集成测试程序；原安卓 PSD FX 容错回归迁移至新测试模块，避免重复旧程序。
- 安卓导入回调同步新版 `ImportOptions`，完整传入 SVG 分组深度和 RAW 去马赛克选项。

文件管理器单文件 256 MiB、同时最多 16 文件等限制不变。Android 系统打印、原生图片剪贴板、手写笔压力/倾斜及 APK HEIC/HEIF 不在本次新增范围。

最终构建、测试结果、设备和未通过项目见完整包 `validation/验证报告.md`。同签名 APK 可直接覆盖升级，不需要先卸载。

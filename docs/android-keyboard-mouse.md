# 安卓键鼠操作

从 0.8.2-android.10（8210）开始，安卓窗口输入支持独立的鼠标左键、右键、中键、横向/纵向滚轮，以及 Ctrl、Alt、Shift、Meta 修饰键。USB 和蓝牙键鼠通过 Android 标准输入接口工作。触摸与鼠标按当前输入事件区分；使用过触屏后仍可用鼠标拖动图层。

默认沿用 Windows Photoshop 的快捷键习惯。菜单显示的 Ctrl 对应键盘 Ctrl，不是 Windows 徽标键。执行条件与点击同一菜单项相同：例如需要选区、可编辑图层或非空文档的命令，必须先满足条件。

## 常用操作

| 操作 | 键鼠方式 |
| --- | --- |
| 选择、绘画、拖动 | 鼠标左键 |
| 图层菜单、画布工具菜单 | 鼠标右键；菜单随工具和点击区域变化 |
| 图层上下排序、移入组 | 拖动图层名称到目标行上/下边缘，或组的中部 |
| 图层多选 | Ctrl+单击逐层切换；Shift+单击连续选择 |
| 复制图层到指定位置 | Alt+拖动图层行 |
| 跨项目复制图层 | 拖到目标项目标签，再在标签或画布上松开 |
| 平移画布 | 中键拖动，或按住 Space 后左键拖动 |
| 滚动画布/列表 | 滚轮；画布上 Shift 或 Ctrl+滚轮横向滚动 |
| 围绕指针缩放 | Alt+滚轮；可在首选项中设置直接滚轮缩放 |
| 临时放大/缩小 | Ctrl+Space / Alt+Space，拖动可连续缩放 |
| 临时移动工具 | 画笔等适用工具下按住 Ctrl |
| 临时吸色 | 画笔等适用工具下按住 Alt，再点击取色 |
| 调整画笔 | `[` / `]` 调整大小；Shift+`[` / `]` 调整硬度 |
| 画布上调整画笔 | Alt+右键拖动；左右改大小，上下改硬度（受画笔 HUD 设置影响） |
| 移动图层/选区 | 方向键 1px；Shift+方向键 10px，具体目标随当前工具变化 |
| 新建/打开/保存/另存 | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| 撤销/重做 | Ctrl+Z / Ctrl+Shift+Z |
| 剪切/复制/粘贴作品内容 | Ctrl+X / Ctrl+C / Ctrl+V |
| 复制图层、编组 | Ctrl+J / Ctrl+G；Ctrl+Shift+G 取消编组 |
| 自由变换 | Ctrl+T；Enter 应用，Esc 取消 |
| 全选/取消选择/反选 | Ctrl+A / Ctrl+D / Ctrl+Shift+I |
| 适合窗口/100% | Ctrl+0 / Ctrl+1 |
| 工具切换 | V 移动，B 画笔，E 橡皮擦，T 文字，M 选框，L 套索，C 裁剪，I 吸管，H 抓手，Z 缩放 |
| 前景/背景颜色 | D 恢复黑白，X 交换 |
| 隐藏面板 | Tab；Shift+Tab 保留工具栏 |

完整的默认绑定表见 [android-shortcuts.md](android-shortcuts.md)。编辑 → 键盘快捷键中可自定义菜单、工具及临时工具按键；也可导入 Photoshop `.kys` 文件中本软件能识别的命令。生成默认参考表：

```powershell
cargo run -p photocraft-ui-egui --example shortcut_reference
```

## 触屏图层操作

在图层名称或缩略图处按住约半秒，继续按住并拖动到目标行的上/下边缘，出现插入线后抬手排序；拖到组的中间可移入组。多选时拖动其中一个已选图层，可一起移动。撤销可恢复原顺序。

静止长按后直接抬手打开图层菜单；不长按直接上下滑动仍用于滚动，分别左滑各行仍用于多选。拖到顶部另一项目的标签仍会复制到该项目。

## 支持边界

此版本使安卓键鼠接通 PhotoCraft 已实现的 Photoshop 风格操作，不代表所有 Photoshop 功能、插件及每个上下文的键鼠行为完全一致。无法识别的 `.kys` 命令不会凭空增加功能。按住任意工具字母后松开回到原工具的完整 Spring-loaded Tools 行为尚未实现；Space/Ctrl/Alt 临时操作按上表支持。

作品内复制粘贴沿用应用内部剪贴板；安卓与其他应用之间的原生图片剪贴板尚未接通。文件打开、保存仍使用内嵌文件管理器。输入文字或编辑数值时，按键优先交给输入框。Alt+Tab、Ctrl+Space 等组合可能被 Android、输入法或桌面环境截获，应用无法接收系统已拦截的事件。

验证环境与实际通过项见 APK 旁的 `validation/验证报告.md`；模拟器输入注入不等同于所有实体键鼠设备的兼容认证。

开发验证可在启动 Activity 时显式传入 `--ez input_diagnostics true`，通过 logcat 的 `PHOTOCRAFT_INPUT` 检查原生指针按键、滚轮和修饰键映射。默认关闭；不记录输入文字。`--ez self_test true` 运行已有的引擎、格式和撤销自检。
